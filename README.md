# MyWorkLog

Windows에서 키보드와 마우스 **활동량만** 로컬에 기록해 업무 흐름을 보여주는
가벼운 Python 데스크톱 앱입니다.

## 개인정보 보호

- 누른 글자나 키 종류를 저장하지 않습니다.
- 마우스 좌표를 저장하지 않습니다.
- 창 제목, 실행 프로그램, 클립보드 내용을 읽지 않습니다.
- 분 단위 횟수만 `%LOCALAPPDATA%\MyWorkLog\worklog.db`에 저장합니다.
- 키를 길게 누를 때 발생하는 자동 반복은 한 번으로 계산합니다.
- 사용자가 직접 추가한 Todo 제목과 세션의 수행 업무 문구는 로컬 DB에 저장합니다.

## Todo와 수행 업무

- `Todo List` 입력란에서 할 일을 추가하고 체크박스로 완료 상태를 바꿉니다.
- Todo를 체크한 순간 활성 업무 세션의 `수행 업무`에 제목이 자동 추가됩니다.
- 여러 업무는 `보고서 작성, 이메일 확인`처럼 콤마로 누적됩니다.
- Todo 이름과 세션의 수행 업무 셀은 더블클릭해서 직접 수정할 수 있습니다.
- Todo 항목을 선택하고 `삭제`를 누르면 목록에서 제거할 수 있습니다.
- Todo를 다시 미완료로 바꿔도 과거 세션에 기록된 문구는 유지됩니다.
- Todo를 삭제해도 과거 세션의 수행 업무 문구는 유지됩니다.

## 설치 및 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 다음을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

설치가 끝난 뒤에는 `Start MyWorkLog.bat`을 더블 클릭해 콘솔 창 없이 실행할
수 있습니다.

창을 닫아도 Windows 트레이에서 기록을 계속합니다. 완전히 끝내려면 트레이
아이콘을 오른쪽 클릭하고 `종료`를 선택하세요.

`Windows 로그인 시 자동 실행`을 체크하면 다음 로그인부터 대시보드 창을
띄우지 않고 트레이에서 바로 기록을 시작합니다. 이 설정은 관리자 권한 없이
현재 Windows 사용자에게만 적용됩니다. 체크를 해제하면 등록도 제거됩니다.

## 업무 세션 계산

기본적으로 마지막 활동 후 10분 넘게 새 활동이 없으면 세션이 끝난 것으로
판단합니다. 화면에서 5~30분 사이로 변경할 수 있습니다. 이는 입력 활동에
따른 추정치이므로 회의, 독서, 생각하는 시간은 실제 업무 시간보다 적게 잡힐
수 있습니다.

## 성능 설계

- 입력 콜백은 메모리의 정수만 증가시킵니다.
- SQLite 쓰기는 10초마다 하나의 트랜잭션으로 합칩니다.
- 마우스 이동은 5초에 한 번만 활동으로 샘플링합니다.
- 화면 갱신은 창이 보일 때만 15초에 한 번 실행합니다.
- SQLite는 WAL 모드와 `synchronous=NORMAL`을 사용합니다.
